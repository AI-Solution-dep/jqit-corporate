# 紹介ページ：見出しを引き継ぐモック

2026-11-12。URL・QRから案内する限定ページ。noindex/nofollow・グローバルナビとサイトマップへの非掲載を維持。

- 章は開発実績・開発体制・進め方・担当者連絡先。共有SectionHandoffで、本文の実見出しが縮小しながら上帯へ移動する。逆スクロールで元の位置へ返す。
- 左の専用カラム・丸アイコン・円形経路・背景流線は使わない。写真・文章・連絡先リンクの幅を保つ。
- 背後の白/薄赤の大きな面が逆方向・別速度で動き、スクロール中も重なりを変える。本文と写真は面より手前。人物の顔を切り抜くマスクは増やさない。
- モバイルでも見出しの受け渡しを残し、面の移動は.32倍。reduced-motionでは面を静止し、現在見出しのみ即時切替。JS無効でも本文と目次のアンカーが使える。
- 数値定義はdocs/design/design-definition.mdの15節を参照。TOPの確定登場と主写真は変更しない。

実装: page.tsx / ChapterNav.tsx / introduction.module.css、components/ui/SectionHandoff.tsx / section-handoff.css。

体制図はTeamDiagramで企業の線画・相談/報告の往復・3担当者への分岐と4専門領域を図示。PCは横、600px以下は縦。連絡先データとアンカーを維持し、写真を架空生成しない。

顧客事例はProjectCasesが公開worksの2件を参照し、課題/担当開発/納品利用状況と詳細・相談リンクを常時表示。自社製品NOVAは後段へ分ける。期間・体制はデータがあるときだけ表示し、サンプル・欠落データは事例として出さない。CMSへの書込みは行わない。
