# JQIT コーポレートサイトの共通デザイン

現行の色・文字・配置・写真・動きの数値定義は [デザイン定義](design-definition.md) を参照。以下は設計意図と変更経緯を含むメモ。

## 基本

白、JQIT赤、薄い赤、紙色、極薄グレーを使う。本文の可読性と写真を主役にし、模様は写真や情報ブロックの背後・画面端へつなぐ。小さい図形を並べず、模様全体を見せるための配置にしない。

## 曲線ルール（2026-11-10）

曲線の種類が多く（波・一角R・正円・四角・枠・菱形）、どれも同じ強さで主張していたため、1種類に絞った。

- 形は「一角だけ大きく曲げる」のみ。残りの角は `--curve-base`（2px）。波・正円・四角・枠の装飾は使わない。
- 大きさは3段階：帯 `--curve-section` / 写真 `--curve-media` / カード `--curve-card`（`app/brand.css`）。px直書きをしない。
- 向き：帯は右下（次の帯へ渡す角）。写真・カードは右上。左右反転レイアウトのときだけ左上。
- 色の違う帯が続くときは、次の帯を角の下へ潜らせて白い隙間を出さない（TOPのカルチャー→パートナー）。
- 背景模様は2種類だけ：角の丸い線（`public/brand/culture-route.svg`）と、一角だけ曲げた薄赤の面。面は画面の内側に見える角を曲げる。下層は `data-depth-scene="plane"` の帯が面、`"route"` の帯が線で、左右交互。
- 例外：ヒーローのメイン写真コラージュ（菱形）は変更しない。記事本文の画像・コードブロック・図解（切り取らない素材）は小さな角丸（4〜12px）のままでよい。
- 薄赤の面は本文の下に敷かない。画面に見える幅を本文コンテナの外側の余白に収め、スマホでは出さない。

## 共通部品

- 配色・曲線・見出しスケール・短い動きは `app/brand.css` に集約し、RootLayoutから直接読む。
- 下層のPageHeaderは淡赤、右下の大きな曲線（`--curve-section`）、共通の文字サイズと余白。背面の正円・走査線・ドット装飾は使わない。
- 見出し帯にはリード文（1〜2行）と写真を置く（2026-11-10）。内容は `lib/page-header-content.ts` に `en` キーで集約し、各ページのファイルには書かない。写真は右列、右上だけ `--curve-media` で曲げ、帯の下端から少しはみ出させて本文へ視線を渡す。写真のある帯では巨大英字を出さない。
- 見出し帯の写真は、同じページの最初のセクションと別の写真にする。ヒーロー用の合成素材（白地に斜めの切り抜き）は枠に収めると白地が写るため使わない。法務ページと記事詳細はリード文のみ/なし。
- ビジョン・AI事業・実績・ニュース・お問い合わせの写真は、既存写真3枚を参考画像に gpt-image-2.5-sunburst（medium）で生成した `public/page-header/*.webp`。人物は実在の社員ではない。社員の実写真が用意できたら差し替える。
- 写真は一角だけ大きく曲げる。製品画面や図解・公式ロゴは切り取らない。
- 一覧カードと記事写真は同じ曲率のルール。法務・フォームは本文を読む/操作する余白を優先する。
- IT/AI事業の情報帯は紙色・濃色文字。写真上の可読性のための暗いオーバーレイとは区別する。

## TOP

- HeroEntranceは肩980ms、全体6380ms。写真常時表示→肩ラベル→コピー→説明→ヘッダー/CTA/操作部。アンカー遷移・戻る・ユーザースクロール時は位置と操作を優先する。
- HomeDesignはモックの確定した曲線・写真の大小・余白を本体へ移したもの。
- HomeScrollDepthは本体専用。比較画面のメッセージ操作は受け付けない。
- 模様は会社情報ブロック右上から抜けるルート線、事業01写真の背面から左端へ抜ける線（スマホは本文に掛かるため非表示）、事業02写真の背面の薄赤の面（左上R）、カルチャーカード右側のルート線。旧来の正円・正方形・枠は曲線ルールに合わせて置き換えた。サービスに模様を足さない。
- 画像内部の移動はIT上・AI下・導入支援上の弱い速度差。枠・文字の最終配置は揃え、reduced-motionでは停止する。
- メイン写真の素材と輪郭は変更しない。

## 2026-11-10 下層の構成と奥行き

前回の共通配色・曲率だけでは、均等な番号付き箱の反復と、下層の動きの少なさが残った。企業理念は定義の行、行動指針は左の導入＋右の6つの文章、DXは実指標の定義リスト、推進体制は文章のまとまりへ変更。事業のQA例はリスト、開発工程は順序に意味がある縦タイムライン、AIの詳細とNOVAは番号のない見出し・特徴リストに変更。コラムは日付・タグと記事本文の2領域を持つ行、認証情報は公式参照リンクの一覧にする。

PageMotionは下層のPageHeaderと記事詳細に配置する。セクション順の図形自動ローテーションは行わない。会社情報のメッセージ写真、Visionの企業理念/行動指針、IT/AIのイントロ/強み・製品帯はdata-depth-sceneで明示。他の一覧・フォーム・記事・規約は本文の先頭セクションの外縁だけに配置し、本文のまとまりごとに装飾を増やさない。

背景面はスクロールに応じて縦横にゆっくり移動し、通り過ぎるにつれて不透明度1から0.1へ減衰する。逆スクロールでは位置に応じて戻す。写真は明示したPhotoDepthの内部だけを拡大1.09倍、移動最大min(24px,写真高4%)で動かす。枠・文章は固定。ロゴ・図解・製品画面は対象外。400pxスクロールのAI事業でPC背景31.55px/写真9.47px、スマホ写真6.34pxを確認。reduced-motionでは移動・減衰を停止し、JS無効時も本文を表示する。TOPのHeroEntrance/HomeScrollDepthは変更しない。

## 2026-11-10 遷移・相談導線・ホバー・見せ場

- **ページ遷移**: `app/template.tsx` の `PageCurtain`。淡赤の面がヘッダー下を覆い、右下の曲線を先頭に上へ抜ける（940ms、最初の3割は静止）。表示中のパスが変わるたびに出す（template は第1階層の変化でしか作り直されないため、幕は pathname を key にして作り直す）。初回読み込み・戻る／進む・reduced-motion では出さない。遷移後は #main にフォーカスを移す。幕の間は `scroll-behavior` を auto にして、ページ先頭へ即座に戻す（smooth のままだと遷移のたびに約1秒スクロールが流れる）。見出し帯の文字・写真の登場は幕に合わせて遅らせる。
- **相談導線**: `SiteClosingCta` を全ページ末尾（フッター直前）に置く。紙色の帯（`--surface-warm`）・右下R・「お問い合わせフォームへ」の行リンク（見出しと同じ和文ゴシック、ホバーで赤）。透かし用の Anton は黒文字で使うと浮くため使わない。暗い帯は目立ちすぎるため不採用（2026-11-10）。/contact と未公開・限定ページには出さない。電話・受付時間は `siteConfig` から読む。
- **ホバー**: マウス端末だけ。リンク内の写真は 1.04 倍、カードは曲げた角が 1.8 倍、フッターのリンクは下線が左から伸びる。
- **見せ場（1ページ1か所）**: CSS のスクロール連動（`animation-timeline: view()`）。非対応ブラウザ・reduced-motion では静止表示。ビジョン=理念の一文が左から現れ、3つの定義は中央に来た行から濃くなる。IT=開発の流れの縦線が赤く伸び、通過した工程の点が赤くなる。AI=NOVAの画面がせり上がり、特徴が順に濃くなる。
- `template.tsx` は Fragment で並べる。ラッパー要素を足すと `#main` 直下前提の PageMotion・scroll-margin が崩れる。
