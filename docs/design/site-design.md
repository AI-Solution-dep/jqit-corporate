# JQIT コーポレートサイトの共通デザイン

## 基本

白、JQIT赤、薄い赤、紙色、極薄グレーを使う。本文の可読性と写真を主役にし、模様は写真や情報ブロックの背後・画面端へつなぐ。小さい図形を並べず、模様全体を見せるための配置にしない。

## 共通部品

- 配色・曲線・見出しスケール・短い動きは `app/brand.css` に集約し、RootLayoutから直接読む。
- 下層のPageHeaderは淡赤、右下の大きな曲線、共通の文字サイズと余白。走査線やドット装飾は使わない。
- 写真は一角だけ大きく曲げる。製品画面や図解・公式ロゴは切り取らない。
- 一覧カードと記事写真は同じ曲率のルール。法務・フォームは本文を読む/操作する余白を優先する。
- IT/AI事業の情報帯は紙色・濃色文字。写真上の可読性のための暗いオーバーレイとは区別する。

## TOP

- HeroEntranceは肩980ms、全体6380ms。写真常時表示→肩ラベル→コピー→説明→ヘッダー/CTA/操作部。アンカー遷移・戻る・ユーザースクロール時は位置と操作を優先する。
- HomeDesignはモックの確定した曲線・写真の大小・余白を本体へ移したもの。
- HomeScrollDepthは本体専用。比較画面のメッセージ操作は受け付けない。
- 模様は会社情報ブロックの背面枠、事業の太線正円と薄赤正方形、カルチャーカード右側の薄灰線。サービスに模様を足さない。
- 画像内部の移動はIT上・AI下・導入支援上の弱い速度差。枠・文字の最終配置は揃え、reduced-motionでは停止する。
- メイン写真の素材と輪郭は変更しない。

## ニュース画像

ITS健保の加入決定記事は画像未入稿のため、JQIT制作の案内図版をフォールバックに設定。公式ロゴではない。公式サイトの画像二次利用は事前照会が必要なので無断転載しない。
出典: https://www.its-kenpo.or.jp/jyouken/index.html
CMSの画像を入稿したら、その画像を優先して置き換える。

## 検証と公開範囲

TOP演出は独立コミット12bf327。共通デザインとニュース案内画像は別コミットにする。
主要な一覧/情報ページ11ルートとニュース/実績/コラム詳細をPC・スマホで表示し、横溢れ/h1/画像読込/共通色を確認。型・ESLint・本番ビルドおよび独立コード/UIレビューを実施する。
ナビ・sitemap・robots・CMS公開状態は変更しない。コミットとローカル表示までで、push・本番公開は別の指示があるまで行わない。

独立レビューで検出した共通CSSの配信欠落はRootLayoutからの直接importへ修正。NOVA本文列の意図しないカード化は、暖色帯のカード用セレクタを実カードだけに限定して修正した。

最終確認: 本番ビルド89ルート生成成功。独立コードレビューで比較用メッセージ制御の残存を除去し重要残件なし。固定ローカルCSS/SVG/画像のみを追加し、認証・権限・秘密情報・HTMLサニタイズ・CSPを変更しないことを手動確認。独立UI再レビューはPC/タブレット/スマホで重要残件なし。RootLayoutは共通CSS import1行のみをコミットし、別件の住所・限定ページ用ヘッダー変更は含めない。
