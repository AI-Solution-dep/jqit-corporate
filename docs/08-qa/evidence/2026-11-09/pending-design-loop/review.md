# デジタル名刺 デザインフィードバック

対象: PR #11。確認日: 2026-11-09。

## 初回レビュー（修正前）

375 / 768 / 1280pxの実画面と既存の紹介ページのスタイルを照合。評価中は実装を変更していない。

1. タグ10px、連絡先ラベル11px、本文14px、専門領域の説明12pxで、スマホでは補助情報が小さすぎる。見出し13pxも本文より弱く、情報のまとまりが読み取りづらい。
2. 詳細のメール・電話リンクの実際のタップ領域が高さ20px。行全体に余白があるのに文字部分しか反応しない。
3. URL欄の文字サイズが12px。iPhoneでフォーカスする際の拡大を避けるため16px以上にする。全文が375px内に収まるか再確認する。
4. コピー・共有の処理中状態がなく、二重操作を防げない。通知表示時にQRコードが上下に動く。
5. 赤・黒・白の配色、罫線、角丸、余分な装飾のない構成は既存サイトと一致。変更する必要はない。

初回評価: 21/27（意匠3、テンプレ感3、統一性2、レイアウト3、レスポンシブ3、可読性1、導線2、操作数3、状態表示1）。

## 1回目の修正と再レビュー

- 本文・連絡先16px、見出し16px、ラベル12px、タグ12pxに拡大。連絡先リンクの高さを20pxから44pxへ。
- URLは16pxの既存欧文フォントに変更。375pxで文字幅280.9px、表示欄327pxとなり全文が収まる。
- コピー・共有の処理中表示と二重操作防止、状態通知の空間を追加。
- 375 / 768 / 1280pxで横はみ出しなし。主要見出しはすべて可視。
- 再レビューで、住所の番地の途中折り返しと、375pxの2列の専門領域説明の不自然な折り返しを検出。
- 状態通知の文字サイズが本文用セレクターに上書きされていたため、専用の指定を修正する。

## 2回目の修正

- 住所を郵便番号・所在地・建物名に分け、数字の孤立を避ける。会社情報は既存定数を継続利用。
- スマホ幅480px以下では4領域を縦リストとし、領域名と説明を横に並べる。新しい部品は追加しない。
- 共有後の案内用空間は保ち、QRコードまでの過大な余白を抑える。

## 最終再評価

- 375pxの郵便番号・番地・建物名に不自然な途中改行なし。4領域は領域名と説明を横に並べた縦リスト、広い画面では2列。

- コピー失敗時の手動コピー案内・URLのフォーカス・全選択を確認。
- 共有処理保留時の「共有中…」・両ボタン無効、完了・キャンセル後の復帰を確認。
- 共有API非対応では共有ボタン非表示。キーボードでURL欄からコピーボタンへ移動し、フォーカス枠が表示されることを確認。
